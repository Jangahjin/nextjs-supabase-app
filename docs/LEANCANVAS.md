# Lean Canvas — Gather (일회성 이벤트 관리 플랫폼)

> 출처: `.claude/agents/docs/PRD.md`. 린 캔버스 9개 블록 순서와 번호는 참고 이미지(`leancanvuse.PNG`)를 따랐다.

## 1. 문제 (Problem)

- 카카오톡 단톡방으로 이벤트를 준비하면 참여자 명단·장소·시간 정보가 대화 속에 묻혀 파악하기 어려움
- 기존 서비스는 대규모 행사(Eventbrite) 또는 정기 동호회(소모임) 중심이라, 생일 파티·워크샵·세미나 같은 5~30명 규모의 **일회성** 모임에는 과하거나 맞지 않음
- 초대부터 참여 확인까지 여러 단계(문자/톡 발송 → 개별 답장 취합)를 거쳐야 해서 주최자의 관리 부담이 큼

## 2. 고객 세그먼트 (Customer Segments)

- 생일 파티, 워크샵, 세미나 등 **5~30명 규모의 일회성 이벤트**를 여는 주최자
- 초대 링크를 받아 참여하는 일반 참여자
- (얼리어답터 후보) 모바일 사용에 익숙하고 카카오톡으로 모임을 조율해본 경험이 있는 소모임 주최자

## 3. 가치 제안 (Unique Value Proposition)

초대 링크 하나로 이벤트 생성부터 참여자 관리, 실시간 참석 현황 확인까지 한 번에 끝낸다.

## 4. 해결책 (Solution)

- 이벤트 생성 시 초대 링크(invite_code) 자동 발급
- 카카오톡/문자/클립보드로 초대 링크 공유
- 링크 클릭 → 로그인 → 자동 참여 처리(별도 신청 절차 없음)
- Supabase Realtime 기반 실시간 참여자 목록
- 이벤트 날짜 기준 예정/진행 중/종료 자동 상태 분류

## 5. 경쟁우위 (Unfair Advantage)

- **일회성 이벤트 특화** 포지셔닝: 소모임(정기 동호회), 카카오톡캘린더(일정 공유만), Apple Invites(기본 초대만), Partiful(관리 기능 부족), Eventbrite(대규모용) 대비 5~30명 일회성 모임에 최적화
- 럭키밀 스타일의 모바일 퍼스트 카드 UI, Google OAuth로 3초 로그인
- 카카오톡 공유·한국어 UI 등 한국 시장 최적화
- (Phase 2) 정산 + 카풀까지 포함한 올인원 관리 — 경쟁 서비스에는 없는 조합

## 6. 수익 흐름 (Revenue Stream)

> PRD에는 "완전 무료 제공"이 차별점으로 명시되어 있을 뿐, 명시적 수익모델은 정의되어 있지 않다. 검증이 필요한 가정으로 남겨둔다.

- 현재: 명시적 수익원 없음(완전 무료 포지셔닝)
- 향후 검토 후보: 정산/카풀 등 Phase 2 기능의 프리미엄화, B2B 임베드(사내 워크샵/세미나용), 광고

## 7. 비용 구조 (Cost Structure)

- Vercel 호스팅 비용
- Supabase 사용료(DB, Auth, Storage, Realtime)
- 초기 개발 인건비(6주 Sprint 기준)
- (선택) 도메인, 마케팅/광고비

## 8. 주요 지표 (Key Metrics)

- 주간 생성 이벤트 수 (목표: MVP 출시 후 1개월 내 50개/주)
- 월간 활성 사용자 MAU (목표: 200명)
- 초대 링크 → 회원가입 전환율 (목표: 70%)
- 이벤트당 평균 참여자 수 (목표: 8명)
- 7일 이내 재방문율 (목표: 40%)

## 9. 채널 (Channels)

- 카카오톡/문자를 통한 초대 링크 공유(참여자 유입의 핵심 경로)
- 초대 링크 기반의 자연스러운 바이럴 확산(참여자가 다음 주최자가 되는 구조)
- 모바일 웹 앱(별도 앱스토어 배포 없이 링크로 즉시 접근)
